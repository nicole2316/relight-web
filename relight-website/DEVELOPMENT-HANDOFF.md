# 开发交接说明

## 项目定位与已确认内容

品牌：光极律动 / ReLight。
定位：驱动数字内容产业的人工智能公司，面向企业提供解决方案。
主要交付方式：API 接入。
模型平台产品：NARRA。
核心技术方向：计算语言学、长文本理解、叙事智能与生成式人工智能。
业务领域：影视、文旅、游戏。

## 已完成页面与交互

当前为单页官网，无路由库、服务端或 CMS。

1. 首页：居中标题与公司介绍、三组预设叙事示例切换。
2. 产品与平台：NARRA 标识、平台介绍、API 接入示意与四步合作流程。
3. 核心技术：计算语言学介绍，以及协同生成、独立审读、长流程运行、数据沉淀四项优势。
4. 业务领域：影视 / 文旅 / 游戏切换与场景介绍。
5. 企业动态：明确标注的待发布区域。
6. 关于我们：公司定位与技术、产品、产业方向。
7. 页脚：品牌、导航、功能入口、点阵波形与备案链接。

导航目标：#products、#technology、#industries、#news、#about；首页 #home。
页脚备案号：陕ICP备2026029623号，链接 https://beian.miit.gov.cn/ 。
右侧圆形入口为 API 接入、交流合作、返回顶部，不是已配置的社交账号。

## 视觉基线

以 PC 展示为主，外层最大宽度约 1700px，主要内容宽度约 1240px，并有移动端适配。
浅灰白底、蓝色点缀；首页标题、布局和现有五个板块已完成一版。
当前背景为 React Bits GradientASCII，采用蓝色 horizon 渐变字符效果与浅色模式，支持鼠标扰动和点击波纹。
全局背景固定于视口底层；页脚采用不透明的浅色底，避免动态背景透出。

## 尚未接入的功能

- 首页故事与解析为静态预设，不调用在线模型。
- API 介绍仅为产品内容与接入示意，未配置真实接口地址、密钥或 SDK。
- 联系 / API 咨询按钮打开同一弹窗。表单仅将需求复制到剪贴板，不提交到服务器、不发送邮件、不持久化。
- 生产环境剪贴板功能通常需要 HTTPS 和用户操作触发；失败时已有提示。
- 招聘职位、投递方式与企业新闻尚待提供。
- 未配置分析统计、登录、客户管理或 CMS。

接手开发时，请先与业务方确认真实 API 文档、合作咨询提交方式、新闻内容和招聘资料。
任何未来的服务密钥都应保留在服务端，不要写入前端代码或 VITE_ 变量。

## 历史文件与依赖

当前未加载的早期文件包括：main.jsx、style.css、editorial.css、humanist.css、LiquidEther.jsx / .css、NeonGlyphs.jsx、PatternWaves.jsx / .css、AeroShards.jsx / .css；public/media/ 为早期首页视频素材。
这些文件保留供参考，不应当作当前入口编辑。

package.json 中的 ogl、vgpu、@vgpu/wgsl 为早期背景依赖，当前 GradientASCII 不依赖它们。为保持原项目完整性，本次未清理历史依赖；vgpu 安装可能涉及较大的 Node WebGPU 依赖下载。若后续只维护当前版本，可同步移除历史组件和相关依赖，并重新生成锁文件、构建验证。
当前背景采用浏览器 WebGL2；不支持时保留静态渐变底色。支持减少动态效果偏好。
